# OGBees UX/UI Designs

`main` holds the approved designs for every product. Work happens on product branches and is merged into `main` only when the team asks for it.

## Products and branches

| Product | Folder | Branch | Who |
|---|---|---|---|
| Website | `website/karim/` | `website/karim-work` | Karim |
| Website | `website/gamal/` | `website/gamal-work` | Gamal |
| Admin portal | `admin-portal/` | `admin-portal/design` | — |

- Open `website/index.html` to compare Karim's and Gamal's website designs side by side.
- Each branch edits only its own folder, so merging a branch into `main` doesn't conflict with the others.
- To add a person or product, create a branch `<product>/<name>-work` from `main` and give it its own folder.
